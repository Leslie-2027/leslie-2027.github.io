There is a concept in the RDMA that's verbs it's standards about RDMA device and driver must do like inputs/expected behavior/success/error conditions without dictating how the operating system or software API implements it.
Example: create QP
ibv_create_qp - create a queue pair



#include <infiniband/verbs.h>
struct ibv_qp *ibv_create_qp(struct ibv_pd *pd, struct ibv_qp_init_attr *qp_init_attr); 

Struct: recording a lot fragmented informations put it as a packet
ibv_create_qp: create queue pair
Pd: protection domain
qp_init_attr: init status defines what kind of requirement i want?


struct ibv_qp_init_attr *qp_init_attr 
# struct ibv_qp_init_attr (about the QP transmission type)
# *qp_initi_attr (* means C programming Pointer, so basically this code means variable to be called at qp_init_attr )



struct ibv_qp_init_attr {
struct ibv_cq          *send_cq;        /* CQ to be associated with the Send Queue (SQ) */
struct ibv_cq          *recv_cq;        /* CQ to be associated with the Receive Queue (RQ) */
struct ibv_srq         *srq;            /* SRQ handle if QP is to be associated with an SRQ, otherwise NULL */
struct ibv_qp_cap       cap;            /* QP capabilities */
enum ibv_qp_type        qp_type;        /* QP Transport Service Type: IBV_QPT_RC, IBV_QPT_UC, or IBV_QPT_UD */
...
};

Struct ibv_srq *srq # Shared Receive Queue
Cap # capability
IBV_QPT_RC # Reliable connection one to one binding
IBV_QPT_UD # Unreliable datagram one to many binding
IBV_QPT_UC # Unreliable connection one to one binding

verbs Application interface
Verbs are architecture but not defined as coding
Verbs API is the coding architect (using C programming architect)

From the diagram, we can see there are two parts within the verbs API,

One : IB_VERBS to create RDMA applications
Example:
ibv_create_qp() # create QP
ibv_post_send() # push down send work request

Two: RDMA_CM connection managment abstration
We can think of connection managment as RDAM managment plane
rdma_listen() #listen to the connection management request
rdma_connect() #confirme connection management

But in the CM managment plane we also can push down data transmission operation
rdma_post_read() #push down the read work request
